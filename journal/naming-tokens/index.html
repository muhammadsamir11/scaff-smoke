Naming tokens after what they do

A token called blue-500 tells you nothing about where to use it. Name it for its job.

The note

The first tokens most teams write are named for their values: blue-500, space-16, font-18. They’re easy to write and hard to use, because the name says nothing about the job.

Name the role instead: accent, surface, body, gap. When the value changes, the name still holds, and a new designer knows which one to reach for.
