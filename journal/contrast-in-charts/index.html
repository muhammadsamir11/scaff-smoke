Chart labels deserve body-text contrast

If people need to read it to decide, it needs the contrast of text, not of decoration.

The note

Chart labels are usually set in a light grey, as if they were decoration. They’re not: they’re how people read the chart.

On Plot we gave every label the same contrast as body text, and moved labels onto the lines. People stopped asking which line was which.
