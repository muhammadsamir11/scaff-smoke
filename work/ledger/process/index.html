Ledger · Process

How the type ramp went from nine sizes to five.

The working steps behind Ledger: what we measured, what we named, and what shipped.

Start a project like this Back to Ledger

Step by step

  1. 01

    Measure the live screens

    We captured every text size in production and found nine, four of them within a pixel of another.

  2. 02

    Name the roles

    Display, title, body, label and figure: each size got a role, and every component took one.

  3. 03

    Set the figures

    Balances moved to tabular numerals at the title size, so columns line up without manual nudging.

  4. 04

    Land it in code

    The ramp shipped as five tokens. The old sizes were deleted, not deprecated.
