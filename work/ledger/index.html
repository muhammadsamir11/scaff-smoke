Interface · Type

Balances first, labels second.

A private bank’s web app. We rebuilt the type ramp and tightened the transaction list so the numbers read before the words around them.

See the process All work
Client
Private bank
Length

Team

The problem

Every screen in Ledger led with its labels. Account names, dates and categories were set larger than the balances they described, so people scanned twice to find a number.

We cut the ramp from nine sizes to five, set figures in tabular numerals, and gave the balance the heaviest weight on every row.
