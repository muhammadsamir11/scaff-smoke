A calendar that stays quiet.

Clinic scheduling. Fewer surfaces, one accent, and a calendar that only speaks up when something changes.

See the the calendar All work
Client
Clinic network
Length

The problem

Ward’s calendar used color for every appointment type, so a full day looked like a warning. Real changes, a cancellation or a double booking, got lost.

Appointments went neutral. The one accent now marks only what needs a decision today.
